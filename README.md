# Amazon Replica 🛒

Live Demo
https://amazon-replica-uw6z.onrender.com

## Description

A replica of Amazon built for learning and demonstration. The project is mostly API-driven, meaning all product data, search, and related operations are handled via backend APIs.

- Cart: stored locally in the browser.

- Orders: stored in the browser, updated and persisted in the database when placed.

## Features
- API-powered product listing with images, ratings, and prices.

- Backend-powered search bar with server-side filtering.

- Cart operations handled in frontend (add items, update quantities, view cart).

- Orders synced with the backend database upon checkout.

- Responsive design for desktop and mobile devices.

## Tech Stack

- Frontend: HTML, CSS, JavaScript (ES6 modules)

- Backend: Node.js, Express.js

- Database: MongoDB

## Installation:

>git clone <your-repo-link>

>cd backend

## Install dependencies:

>npm install

## Start server:

>npm start


Open http://localhost:4090 in your browser.
